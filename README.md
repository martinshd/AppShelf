# AppShelf

自从mac上没了Launchpad之后，查看应用感觉很不爽，四指合拢之后看到的“应用程序”、不能分类、不能挪动。
所以自己做了一个称手mac上的应用架子：常用应用随手钉住、按自己的方式分组，想找哪个一搜就开。

AppShelf 是一款 macOS 应用启动器。它扫描系统里的应用，用一张整齐的网格展示出来，点击即可打开。适合应用装得多、在「应用程序」里翻找费劲的人。

[下载安装](https://github.com/martinshd/AppShelf/releases) · [使用说明](docs/usage.md) · [反馈问题](https://github.com/martinshd/AppShelf/issues)

## 能做什么

- **全部应用一张网格**：自动扫描「应用程序」等系统应用目录，按名称排列展示。
- **置顶常用应用**：右键置顶后固定在网格上方，拖拽即可调整顺序，重启后仍然保留。
- **自定义分组**：按工作、设计、开发等自己的方式建组，从应用右键菜单把应用加入分组。
- **只搜名字**：搜索框只匹配应用名称，不掺杂文件和其他结果。
- **全局快捷键**：`Option + 空格` 随时呼出或收起 AppShelf。
- **访达中显示**：从右键菜单直接定位应用的安装位置。

界面跟随系统语言，支持中文和英文。没有主窗口之外的常驻入口干扰，不用时收起即可。

## 开始使用

首版需要 **Apple 芯片（M 系列）Mac，macOS 14 或更高版本**，暂不提供 Intel 安装包。

**这是未通过 Apple 公证的免费预览版**，首次打开可能出现开发者验证提示。安装前请阅读[使用说明](docs/usage.md#安装预览版)。

1. 从 Releases 下载安装包，按照该版本说明安装。
2. 打开 AppShelf，应用列表自动加载。
3. 右键应用可以置顶、加入分组或在访达中显示。
4. 按 `Option + 空格` 可以随时呼出或收起窗口。
