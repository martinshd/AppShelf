# AppShelf 使用说明

## 安装预览版

当前版本是未通过 Apple 公证的免费预览版，仅提供 Apple 芯片（M 系列）安装包，需要 macOS 14 或更高版本。

1. 从 [Releases](https://github.com/martinshd/AppShelf/releases) 下载 `AppShelf-<版本>.dmg`。
2. 双击打开 DMG，将 `AppShelf.app` 拖到「应用程序」文件夹。
3. 首次打开时，如果系统提示开发者无法验证，仅在确认来源可信且愿意试用时：在「应用程序」中找到 AppShelf，按住 Control 点按图标并选择「打开」，在弹出的对话框中再次确认；或到「系统设置 → 隐私与安全性」选择「仍要打开」。详见 [Apple 说明](https://support.apple.com/zh-cn/102445)。
4. 如果系统提示应用已损坏或是恶意软件，请停止操作，核对下载文件的 SHA-256 校验值（每个 Release 附件中提供 `SHA256SUMS.txt`），仍不一致请到 Issues 反馈。

校验方法（在「终端」中执行）：

```bash
shasum -a 256 ~/Downloads/AppShelf-<版本>.dmg
```

将输出的值与 Release 中 `SHA256SUMS.txt` 的内容对比，一致说明文件完整。

## 界面布局

- 左侧边栏：「全部应用」「已置顶」和你创建的分组。
- 右侧网格：当前选中的应用集合。「全部应用」视图下，置顶应用固定显示在网格上方。
- 顶部搜索框：只按应用名称搜索。
- 工具栏「刷新应用」：重新扫描应用目录。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 打开应用 | 单击应用图标 |
| 置顶 / 取消置顶 | 右键应用图标，选择置顶相关操作 |
| 调整置顶顺序 | 在「置顶」区域或「已置顶」视图中拖拽图标 |
| 新建分组 | 点左侧边栏「我的分组」右侧的 + 按钮 |
| 加入分组 | 右键应用图标，从菜单中选择目标分组 |
| 删除分组 | 右键左侧边栏中的分组名称，选择「删除分组」 |
| 在 Finder 中显示 | 右键应用图标，选择在 Finder 中显示 |
| 呼出 / 收起窗口 | 按 `Option + 空格` |

## 数据与隐私

- 置顶列表和分组信息保存在本机，不上传任何数据。
- 应用只读取应用目录（`/Applications`、`/System/Applications`、`~/Applications`）获取应用名称和图标。
- 应用不包含统计或遥测。

## 已知限制

- 仅支持 Apple 芯片 Mac，暂无 Intel 安装包。
- 界面目前只有中文。
- 未做 Apple 公证，首次打开需要按上述步骤确认。
- 搜索只匹配应用名称，不支持拼音、缩写或搜索文件。
